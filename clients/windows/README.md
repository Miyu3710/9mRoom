# 9mRoom · Windows 客户端

## 当前状态

**采集 + 常驻化 + WPF 界面可用。** 前台窗口、SMTC 音乐、空闲检测、appId 映射、WebSocket 上报都已打通；
客户端支持托盘、关闭到托盘、单实例、开机自启、配置持久化与断线重连。

## 目录

```
clients/windows/
├─ src/
│  ├─ NineMRoom.Client.Core/     采集与协议（可复用类库）
│  │  ├─ Native.cs                Win32：前台窗口 / 空闲 / 进程名
│  │  ├─ ForegroundWatcher.cs     前台应用轮询与变化事件
│  │  ├─ MediaWatcher.cs          SMTC 媒体会话
│  │  ├─ AppCatalog.cs            进程名 → appId / 类别（读 shared/app-catalog）
│  │  ├─ StatusComposer.cs        组装状态块
│  │  ├─ StatusRenderer.cs        状态块渲染（与 fixtures 对齐）
│  │  └─ PresenceClient.cs        WebSocket 上报与房间成员
│  ├─ NineMRoom.Client.Cli/       无界面探针（验证采集与协议）
│  └─ NineMRoom.Client.App/       WPF 界面
│     ├─ Services/                托盘 / 单实例 / 设置 / 自启
│     ├─ ViewModels/              主界面状态与成员同步
│     ├─ Themes/Tokens.xaml       由 design/tokens.json 生成，不入库
│     └─ app.manifest             PerMonitorV2 DPI
├─ build.ps1
├─ run.ps1                        运行探针
└─ run-app.ps1                    运行 WPF 客户端
```

## 构建与运行

```powershell
# 服务端
..\..\server\run.ps1

# 客户端（自动生成 tokens 并构建 CLI + WPF）
.\build.ps1
.\run-app.ps1
```

启动后会自动连接（可在连接栏取消「自动连接」）。开机自启时使用 `--minimized` 静默启动到托盘：

```powershell
.\run-app.ps1 --minimized
```

关闭窗口默认隐藏到托盘；托盘菜单可以显示主窗或退出。

无界面探针仍保留，用于排查采集问题：

```powershell
.\run.ps1 --seconds 20 --room demo --name WindowsProbe
```

| 探针参数 | 说明 |
| --- | --- |
| `--server` | 服务端地址，默认 `http://127.0.0.1:5080` |
| `--room` / `--name` | 房间与昵称 |
| `--seconds` | 运行秒数，0 表示直到 Ctrl+C |
| `--no-send` | 只采集，不连接服务端 |
| `--show-title` | 控制台显示窗口标题（默认不显示，也永不上传） |
| `--log` | 追加写入日志文件 |
| `--render-check <fixtures.json>` | 跑状态块渲染一致性用例 |

## 已实现

- 前台窗口：`GetForegroundWindow` + 进程名，每秒轮询；UWP 应用会解析 `ApplicationFrameHost` 的子窗口
- SMTC：标题、歌手、专辑、播放状态、进度与总长，2 秒刷新
- 空闲：`GetLastInputInfo`，满 5 分钟把 mode 切到 `away`
- 应用映射：`shared/app-catalog/catalog.json`，未收录归 `other`
- 上报：每 3 秒 `presence.update`，块为「应用 / 音乐 / 开机时长」
- 房间成员：解析 snapshot 与 presence.changed，界面实时更新
- 状态块渲染：C# 实现与 `shared/status-blocks/fixtures.json` 全部用例一致
- 视觉：`design/tokens.json` 生成 WPF 资源，深色主题
- 常驻：托盘图标与菜单、关闭到托盘、单实例激活、静默启动参数
- 可靠性：断线指数退避重连、界面显示上次同步时间
- 配置：服务器 / 房间 / 昵称 / 自启 / 自动连接落盘；写入失败时自动回落到 exe 同目录
- DPI：PerMonitorV2 manifest
- 设置页：主窗侧边栏页面，含启动与常驻、隐私（音乐共享开关）、通知、叠加层（开关 / 点击穿透 / 四套预设 / 自定义主题 / 位置重置）、版本、配置与日志目录
- 叠加层主题：预设 / 自定义；色板 + 十六进制颜色、系统字体选择、字号档位、字重、单行自动换行，设置页内嵌实时预览，支持导入导出 JSON
- 连接流程：先填写服务器地址连接服务器（`/healthz`），不进入房间；房间页居中显示“你未进入房间”，点“加入房间”打开遮罩，输入房间号与昵称
- 加入选项：可记住默认昵称；仅服务端创建的房间可设为“家”，下次连接自动加入；用户房间不能设为家
- 自习室四标签：状态（连接设置逐行 + 我的状态，模式高亮）/ 房间（成员）/ 日志（秒级时间；本次连接加入、离开、改名、模式切换）/ 聊天（本次连接，500 字、服务端限频），页面级滚动条贴窗口
- 手动状态：自动 / 专注 / 休息 / 离开 / 隐身；隐身时不展示状态，只显示“隐身中”；托盘可暂停上报或隐身
- 番茄计时：25 / 45 / 60 分钟倒计时，开始 / 暂停 / 重置，运行中作为 timer 块同步
- 待办页：标题、可选起止时间、子任务；全部子任务完成才算完成，支持置顶；状态只同步标题与进度
- 应用页：图标卡片列出探测到的应用，支持最近使用 / 名称 / 分类排序；点击卡片以主窗遮罩面板查看规则
- 应用规则面板：显示可执行文件路径，可改显示名、自定义图标，覆盖模板 / 分类（“自动”= 不覆盖，当前分类高亮），支持忽略与隐藏标题；图标文件缓存，失败回退文字
- 状态页：预览置顶并显示昵称；块显隐、拖拽（跟手预览 + 插入线，可拖到末尾）、增删、模板覆盖；自定义块最多 5 个，占位符逐项说明收进 `?` 弹层
- 全局快捷键：`Ctrl+Alt+Shift+T` 开始/暂停计时，`Ctrl+Alt+H` 显示/隐藏叠加层
- 隐私：音乐共享开关；窗口标题默认关闭，开启后为黑名单模式（除黑名单外共享），标题只随 presence 到服务端内存，隐身或关闭即清空
- 专注统计：本地按天累计，设置页查看近 7 天与合计，可一键关闭；仅上报今日总秒数
- 每日目标：目标分钟数可设，状态卡显示进度条与达成 / 还差多少，并按本地日期计算连续达标天数
- 叠加层连接灯：右上角呼吸灯，已连接绿色、重连黄色、离线灰色
- 设置在字体 / 背景窗口中修改时，叠加层实时预览；取消会恢复原主题
- 字体列表优先显示中文名，滚轮一次一项；字号直接输入
- 颜色选择提供完整颜色画盘，不再只有预设色
- 背景窗口颜色/圆角/宽度/位置/单双行修改时，叠加层同步实时变化；取消恢复原主题
- 预览中的名称使用“文字色”，状态与标题使用“次要色”
- 设置“关于”支持检查 GitHub Releases 更新，发现新版本可直接前往下载
- 应用规则：文件位置可编辑；任意文件可提取关联图标（优先 .exe），图片文件直接使用；单应用模板 > 分类模板 > 全局模板
- 应用分类：可新增 / 删除 / 拖动排序分类（如“工具”），分类可配置 app 块模板；删除后应用回到“自动”，应用卡片显示分类名称
- 应用搜索：按显示名、原应用名、进程名、分类搜索；搜索框在排序行右侧，内置 × 清空
- 自定义状态块：支持 `${...}` 在本机执行终端命令或 PowerShell 脚本（如 `${&'C:\scripts\uptime.ps1'}`），15 秒缓存、2.5 秒超时、输出清洗截断
- 导航：自习室 / 专注 / 状态 / 设置；自习室纵向排列状态与成员
- 外观：无边框主窗 + 自定义标题栏，DWM Mica/亚克力回退玻璃渐变，4px 细滚动条，深色托盘菜单
- 打包：`packaging/package.ps1` 生成自包含便携 zip 与 per-user MSI；发布包要求 `-Sign` 签名，当前开发环境无证书，暂为未签名构建
- 性能：空闲约 0.05% CPU（16 线程）/ 约 225 MB（Debug）；发送间隔 3s / 空闲 15s / 隐身 30s / 暂停 0
- 多显示器：叠加层按所在显示器的工作区定位，并在该屏幕内重置位置
- 托盘：提示与菜单首行显示房间、在线人数与当前状态，暂停时显示“已暂停上报”
- 成员详情抽屉：点成员查看模式、最近同步、今日专注、完整状态、窗口标题与设备，Esc 关闭
- 日志：按天写 `client-YYYYMMDD.log`，超过 4 MB 切分，保留 7 天；LocalAppData 不可写时回落到 exe 同目录
- 屏幕叠加层：透明置顶、不抢焦点、不进 Alt+Tab、可拖动并记忆位置；显示房间内所有成员状态（在线优先、离线置灰）；支持极简 / 紧凑 / 卡片 / 字幕条四套预设
- 自定义主题：背景/文字/次要/边框色、字号、透明度、圆角、内边距、宽度、单/双行、位置；JSON 导入导出、可从当前预设复制

## 环境说明

**托盘图标要求正常权限启动。** Windows 会拒绝低完整性进程注册托盘（`Shell_NotifyIcon` 错误 5），
而当前自动化会话启动的子进程是 Low 完整性。因此调试时可能出现「进程在跑但没有托盘图标」：
此时客户端会提示并改为「关闭即退出」，不会留下找不到入口的后台进程。

从桌面双击 `9mRoom.cmd`（或直接运行 exe）会以正常权限启动，托盘应正常出现。
Windows 11 默认会把新图标放进任务栏的 `^` 隐藏区，可右键固定。

当前沙箱也会拒绝客户端进程写 `HKCU\...\Run`，所以「开机自启」在本机会回退为关闭并给出提示；
在普通桌面环境下应可正常写入。若遇到同类问题，备用方案是计划任务或启动文件夹。

本地 SDK 在仓库根的 `.tools/dotnet`，脚本会把 `DOTNET_CLI_HOME`、`NUGET_PACKAGES`、
`APPDATA`、`LOCALAPPDATA`、`TMP` 全部重定向到 `.tools/`。
当前机器上用户目录的临时目录权限异常，不重定向会导致 MSBuild 失败。

首次 restore 需要 `Microsoft.Windows.SDK.NET.Ref`（SMTC 投影），需要代理；
之后走本地缓存即可离线构建。
