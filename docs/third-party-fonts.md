# 第三方字体

## MiSans

- 字体：MiSans
- 版权：Xiaomi
- 官方页面：https://hyperos.mi.com/font/zh/
- 字体文件镜像：https://github.com/boyan01/mi_sans_font
- 使用字重：Regular、Medium、Semibold、Bold
- 位置：`clients/windows/src/NineMRoom.Client.App/Assets/Fonts/`
- 加载方式：WPF `Resource` 内嵌字体，不要求用户安装

MiSans 官方说明其可免费商用。`LICENSE-MiSans-Repo.txt` 是字体文件镜像仓库的 MIT 许可证，不等同于 MiSans 字体本身的授权条款；字体授权以小米官方页面为准。
