# design

「统一 UI 风格」的落地物。跨端统一靠 tokens 与验收，不依赖同一个 UI 框架。

## 计划放什么

| 文件 / 目录 | 内容 |
| --- | --- |
| `tokens.json` | 颜色、字号、间距、圆角、动效时长、阴影（唯一来源） |
| `icons/` | SVG 源文件，两端各自转成可用格式 |
| `reference/` | 参考实现截图，仅保留在设计阶段，不入公开仓库 |

## 参考屏

`reference/` 下两张图取自参考实现，只借鉴交互与信息密度，**不照搬配色与素材**。为避免公开仓库携带第三方界面截图，公开版本不包含这两张图。

共性：深色背景、卡片式分组、状态行用「 | 」分隔、每个块自带 emoji 前缀。

## 生成方式

`tokens.json` → `Tokens.xaml`（WPF ResourceDictionary）与 `Theme.kt`（Compose Theme）。
生成脚本可以后补，前期先保证两端读的是同一份数值。

## 原则

- 先定四组：颜色（含深色）、字阶、间距（4 的倍数）、圆角
- 品牌色一个，语义色四个：专注 / 休息 / 离开 / 离线
- 中文字体使用系统字体，避免字体授权与包体膨胀
- 图标统一线性风格、24px 网格、1.5px 描边
- emoji 在 Windows 与 Android 上字形不同，状态块只用 emoji 做前缀点缀，不承载唯一语义
